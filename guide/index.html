BBTK The Audition — user guide

The application works offline and keeps the imported source pack intact. All changes happen in an editable project copy.

Start

Run BBTK-TheAudition.exe with its PCK and bin folder beside it. Create a project, open an existing project.bbtk, or import a mod pack from the welcome screen. Tools opens independent resource tools. Guide opens the online documentation; Help → Offline guide opens the local copy. Home returns to the menu without closing your project. Resume Project appears only when a valid project is loaded.

Three bundled menu tracks start in a shuffled order and continue from one track to the next. Settings → Audio lets you add MP3, OGG or WAV files, remove added tracks, skip to the next track, mute playback and change volume. Analysis happens locally and is cached: each song has a detected beat map, tempo segments and an estimated introduction transition. Tempo detection is an estimate; sync varies with recording quality and rhythmic ambiguity. The intro adapts to each song, with quick entrances and a reveal within two bars. Menu pulses use quarter notes grouped in 4/4; alternating strong and weak accents do not automatically reduce the pulse to half-time. Space, Enter, Escape or Skip intro opens the menu at its transition point.

The mascot uses a continuous skinning mesh with head, torso, arm, leg and tail bones. Shared joints keep the illustration intact throughout movement. Its groove, the title and all menu buttons follow the selected song's beat map. The black checkerboard drifts diagonally with a subtle wave. Settings → Appearance controls the introduction and Reduce Motion. Reduced motion keeps the background static and disables puppet motion, title/button pulses and flashes. The footer contains Settings, Support, Report a Bug and Quit; the version is at bottom right. Menu music fades when entering the editor and resumes on Home. It is never copied into an exported mod pack.

File → New project creates a pack and a first level with Virgin, Normal and Expert charts. File → Import pack asks for the folder containing act.cfg, then a parent directory for the editable copy. Each project contains project.bbtk, pack/, .cache/, .autosave/ and optional .assets/ archives for reversible images.

Main workspace

The left dock contains the level selector and resource library. Search resources, import media, or drag a resource onto the timeline. The center shows the scene. The right dock edits selected notes, events or resource properties. Resize the three dock dividers to suit your screen.

The charcoal theme uses orange actions, clear headings and contextual tooltips. Tools → Pack / Levels shows cover cards; double-click a card to open its level. Fonts come from Windows and are not bundled game assets. The default preview uses an animated black/charcoal checkerboard. Imported background artwork is displayed from the mod's own resource.

The bottom transport chooses a difficulty and editing mode. Chart, Scene and Audio switch the timeline tracks. Ctrl+wheel zooms around the pointer; wheel pans time; middle drag pans; Alt+wheel scrolls scene/audio tracks. Click the waveform or beat ruler to seek. The orange cursor uses chart seconds.

Music and timing

Import your audio, then choose Assets configuration and set song_path to its filename in the level's audio folder. Music & offsets edits song_offset. Chart time = music time − song_offset. Preview supports WAV, MP3 and OGG; the converter produces Vorbis OGG. Native reference media uses Vorbis.

The waveform is generated in the background and cached. Choose a snap division or Free. BPM events change the grid without moving existing notes. Tools → Tap tempo measures repeated taps and adds a BPM event at the cursor after you accept. Analyze BPM suggests a value for you to check by listening; it does not chart notes. Loop sets start, end and playback speed. Metronome follows the musical grid.

Chart editing

↓ = input 0, → = input 1, ← = input 2, ↑ = input 3.

In Step Edit, an arrow adds the selected note type and advances one grid division. For a hold, press its arrow at the start, navigate to the end, and press it again. In Record, start playback and press arrows in time. For holds, press and release the arrow to define both ends. Text fields suspend chart shortcuts.

Double click an empty chart lane to insert a note. Click notes to select them, Ctrl+click to extend/toggle selection, or drag an empty rectangle to select a group. Drag notes to change time/input; drag a hold tail to resize it. The inspector applies changed properties to all selected notes. Unknown note fields remain present.

Copy/Paste uses timestamps relative to the first selected note and the current cursor. Quantize snaps selected timestamps and hold ends. Shift selection moves a section by seconds and input delta. Voice toggle changes trigger_voice. Save pattern stores relative notes in the project library; Patterns inserts them into any difficulty at the cursor.

Scene and audio

Select a track beside + Event. Fill its properties and apply. Supported native tracks include animation loops, camera, background, effects, shutters, flags, video, BPM, sound loops, one-shots, voices, toy and vibe_control.

Animation events store filenames and h/v/total grid data. Alternate switches the preview's alternate animation. Drag the preview or use its wheel to position/zoom a camera, then add a Camera event to retain that view at the cursor. Camera speed is transition duration in seconds.

Audio loops accept one filename or a list; voices use voice_paths. Banks cycle in note order, and trigger_voice selects notes that play voice audio. One-shots use their own timeline timestamps. Device tracks remain file based with a preview indicator; the toolkit does not connect to hardware.

Seek reconstructs camera, current animation and bank indices. Paused OGV seeks use cached FFmpeg frames. Playback uses Godot's Theora player. The editor preview continues through the end of final video and timed effects, even after the music finishes. Stop flags are preserved and prompt before continuing. Problems offers a reviewable post-song delay fix when a final video extends beyond the native game duration.

Spritesheet Maker

The welcome Tools hub and Tools → Spritesheet Maker accept image sequences, GIFs and video. Add images, sort numerically or reorder with the arrows. GIF/video extraction accepts a start time, FPS and frame count. Extraction can be cancelled.

Choose columns/rows and a common frame size. Default is 2×3, six 1280×720 cells. Fit centers each image with transparent padding, Crop fills and clips the cell, and Stretch scales it directly. Build preview before saving. Animate preview uses your FPS. Save PNG + grid metadata adds the resource to the library. Dragging it into the timeline uses the stored h/v/total.

In standalone mode, Save exports PNG and a CFG with h, v, total and FPS. Keep that CFG beside its PNG: importing the PNG into a project reads its grid automatically. Add to Project copies the sheet into an already open level as an undoable edit.

Split existing sheet extracts the requested frame count into an empty output directory. Image replacements keep archived versions for undo/redo.

Independent tools

The Tools hub works without a project. Media Converter lets you choose a source, trim start/duration and an output folder. It produces native Vorbis OGG or Theora OGV. Cancel stops the conversion without registering an incomplete asset. Tap Tempo / BPM accepts taps or a chosen music file and lets you copy the result. Charts, pack management and playtest require an open project.

Cutscene Editor

In standalone mode, Open storyboard reads an exported storyboard folder; Export storyboard writes native pre/post CFG scripts and their shots/audio. Add to Project copies the result into an open level, preserving existing nonempty cutscenes. A storyboard with unexported changes asks before closing.

Choose Before level or After level. Add, duplicate, reorder or remove storyboard panels. Each panel edits src, character, dialogue, audio and optional transition. Dialogue supports Godot BBCode. Import shot writes cutscene/shots; Import audio writes cutscene/audio. Enter the imported filenames in panel properties.

Characters edits the preserved character list. Global audio tracks can start, end, pause and resume across zero-based panel indices, with a fade duration. Preview Next advances the storyboard and plays panel/global audio. Stop audio ends the preview. Apply panel commits one undoable operation.

Pack management

Tools → Pack / Levels edits pack metadata, creates/duplicates/reorders levels, removes a level from the exported pack, and adds difficulties. Metadata includes author, description, color, character, IDs and existing prerequisite values. New fields and unusual native variants can be added in Native CFG Editor.

Required cover filenames live in level/images: thumbnail.png and splash.png. Import them through the library. Removing a level retains its media for undo.

Resource Manage displays every use of the selected resource. Rename or Replace updates those exact references. Remove from catalog requires zero uses and keeps the file available to history. Excluded resources are omitted from exports.

Playtest

Select Playtest or press Ctrl+T for manual input. Autoplay or Ctrl+P runs the chart. Incoming notes, timing feedback, score and combo appear in the preview. Stop opens the timing report. This profile is experimental; the Compatibility dialog and known-limitations document describe validation still required against the game. Use Install for test and the real game for final acceptance.

Save, recovery and export

Ctrl+S saves the canonical project then mirrors its native pack files. Undo/redo covers document commands and imported/renamed/excluded resource state. Recovery snapshots are written separately every 10 seconds while changes remain pending. Opening a project offers a newer recovery snapshot; File → Recover autosave also restores it. A cancelled conversion does not insert an incomplete asset.

Problems lists missing resources, invalid notes/holds, duplicate IDs/indices, negative timestamps, invalid grids/BPM and events beyond the music duration. Double click to navigate; Replace selected missing resource repairs a missing file. Warnings preserve your data. Export errors must be resolved first.

Export folder creates one pack directory in the selected parent. Export ZIP creates one top-level pack directory containing act.cfg, level configurations and media. Project settings, caches and recovery data stay outside it. Preferences optionally includes official editor caches. Install for test chooses the actual mods folder and backs up the prior pack to sibling bbtk-backups before replacement. Open game uses the executable selected in Preferences.

Advanced editing

Native CFG Editor lists all retained CFG files, including device and future fields. Double click a document, edit native Godot Variant syntax and Apply. Syntax and known structural contracts are checked before commit. Arrays in forms use the same syntax; typed arrays and Godot values are preserved.

Keyboard shortcuts are configurable in Help → Keyboard shortcuts. Preferences also sets FFmpeg/FFprobe and the game executable paths.
